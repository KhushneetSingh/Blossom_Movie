# Contributing to Blossom Movie 🌸

Thank you for considering contributing to Blossom Movie! Every contribution helps make this project better.

## How to Contribute

### Reporting Bugs

If you find a bug, please [open an issue](https://github.com/KhushneetSingh/Blossom_Movie/issues/new) with:

- A clear, descriptive title
- Steps to reproduce the issue
- Expected vs actual behavior
- Your environment (Xcode version, iOS version, device/simulator)

### Suggesting Features

Feature requests are welcome! Please [open an issue](https://github.com/KhushneetSingh/Blossom_Movie/issues/new) and describe:

- The problem you'd like to solve
- Your proposed solution
- Any alternatives you've considered

### Pull Requests

1. **Fork** the repository
2. **Create a branch** from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Set up your environment** — follow the [Getting Started](README.md#-getting-started) guide
4. **Make your changes** — keep commits focused and well-described
5. **Test** your changes on at least one iOS simulator
6. **Push** your branch and open a pull request

### Code Style

- Follow standard Swift conventions and [Swift API Design Guidelines](https://www.swift.org/documentation/api-design-guidelines/)
- Use SwiftUI's declarative patterns
- Keep views small and composable
- Use `async/await` for asynchronous work

### API Keys

Never commit your `APIConfig.json` file. It is gitignored for a reason. Use the provided `APIConfig.template.json` as a reference.

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).
